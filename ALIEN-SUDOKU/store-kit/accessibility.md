# Accessibility Nutrition Labels (App Store Connect → App Accessibility)

Voluntary today (Nov 2026). Claim only what was tested end to end on a real iPhone; these
answers reflect what the game supports. Test each one on TestFlight before claiming it.

| Feature | Answer | Why |
|---|---|---|
| VoiceOver | **No (for now)** | Board cells have spoken labels ("Row 3, column 5: " plus the glyph's name), but menus and the duel panel haven't been tested end to end with VoiceOver |
| Voice Control | No | Not tested |
| Larger Text | **Yes, after a TestFlight check** | Settings → Text size, Auto follows Dynamic Type (100–150%) |
| Dark Interface | **Yes** | The game is dark by default (Easy has light and dark color schemes) |
| Differentiate Without Color Alone | **Yes** | Glyphs differ by shape and picture, not only color |
| Sufficient Contrast | **Not yet measured** | Check text against panels (4.5:1) in every theme, including the light Easy schemes, before claiming it |
| Reduced Motion | **Yes** | Settings → Reduce motion, and the phone's Reduce Motion setting is honored |
| Captions / Audio Descriptions | Not applicable | No spoken audio or video |
