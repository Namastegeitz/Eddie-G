# Bug's-Eye View: Codex task prompts

Small, well-scoped tasks for Codex (or any coding agent that works best with
one clear change at a time). Each names the files, the change and the check.
Project: `apps/bugs-eye-view` (Godot 4.7, GDScript). After any change run
`tools/run_tests.sh` from that folder; it must print `ALL CHECKS PASSED`.
Content in `scenes/` and `resources/` is generated by `tools/builders/`; edit
the builder and regenerate with
`godot --headless --path . res://tools/build_all.tscn -- --force --only=res|actors|levels`.

---

**1. Food combo bonus**
In `scripts/world/level.gd`, when the player eats two different bug foods
within 5 seconds, show "COMBO!" and add 50 points (new `combo_points` in
`scripts/data/scoring_config.gd`, a `combos` counter in
`scripts/core/run_stats.gd`, a line in `score()`). Add an audit check in
`tests/phase_audit.gd` section 9.

**2. Gem radar beep**
Add a `gem_radar` setting (Settings menu toggle, default on). When an uncollected
crumb gem is within 20 units, play a soft beep every 1.5 s, faster when closer.
Files: `scripts/ui/settings_menu.gd`, `autoload/save_system.gd`, a new
`scripts/world/gem_radar.gd` added by `Level`. Test the beep interval.

**3. Effect timer bars**
Replace the text effect list (`_effects` in `scripts/ui/hud.gd`) with small
coloured bars (colour from the item's `ItemDef.color`) that shrink as the
effect runs out. Keep `PowerUps.label()` for the text. Check that a bar
appears for Sugar Rush and disappears when it ends.

**4. Spoiled food**
Add a `spoiled` flag to `ItemDef`: spoiled food makes the bug slow
(`set_slowed(0.6, 4)`) instead of helping. Place one spoiled cheese in the
backyard compost. Visual: greenish tint. Test that eating it slows the bug.

**5. Human sneezes**
Every 40-90 s a present human sneezes (`voice_huh` pitched up is fine for
now): the head jerks (`Torso/Head` rotation), and for 1 s it can't see. In
`scripts/threats/human.gd`. Test that `can_see()` is false during a sneeze.

**6. Cat stretches on wake**
When the cat's nap event ends, play a 1.5 s stretch (body pitch forward, tail
up) before it patrols. `scripts/threats/pet.gd`. Test the cat doesn't move
during the stretch.

**7. Crumb trail hint**
Holding Sense as the cockroach for 2 s draws a faint dotted line to the
nearest crumb for 3 s (reuse the `SenseArrow` direction logic in
`scripts/bugs/cockroach.gd`). One `ImmediateMesh`, no per-frame allocations.

**8. Pause screen stats**
Show the current run's crumbs, foods eaten, gems found and alarm count on the
pause menu (`scripts/ui/pause_menu.gd`, read `Level.current.run`).

**9. Save migration test**
Add a test that loads an old save without the `gems` key and without
`gem_hunter` in level badges, and checks nothing crashes and the defaults are
filled in (`autoload/save_system.gd` `_merge`).

**10. Meshy dry-run in CI**
Add a step to `tools/run_tests.sh` that runs
`python3 tools/meshy/generate.py --dry-run` and fails if any `model_id` used in
`scenes/` is missing from `tools/meshy/assets.json` (the audit checks this
too, but this runs without Godot).
