# Credits and asset rights

Every asset needs a licence that allows selling the game in stores. Checked 27 Nov 2026.

| Asset | Source | Licence / rights | Status |
|---|---|---|---|
| Game code (GDScript, tools) | Written for this game | Yours | OK |
| Godot Engine 4.7.2 | godotengine.org | MIT - credited in Settings > Privacy & about ("Made with the Godot Engine") | OK |
| Godot's default UI font | Bundled with Godot | OFL 1.1 / Apache 2.0 (ships with the engine) | OK |
| Rooms, people, pets, bugs, props (built from code) | `tools/builders/*` | Yours | OK |
| Textures | Generated by `tools/generate_textures.py` | Yours | OK |
| Sound effects and music | Synthesized by `tools/generate_assets.py` | Yours | OK |
| Fridge and groceries 3D models (`assets/models/*.glb`) | Meshy AI | Rights depend on the Meshy plan at the time of generation: paid plans grant commercial use; free-plan output is CC BY 4.0 (needs attribution) | **CHECK** your Meshy plan for 17 Nov 2026; if it was free, add "3D models made with Meshy (CC BY 4.0)" to the credits |
| Store-art title font (Inter Display Black) | rsms.me/inter | OFL 1.1 - free for commercial use | OK |
| Sentry Godot SDK (in release builds) | getsentry/sentry-godot | MIT | OK |
| Firebase Crashlytics (Android release builds) | Google | Android SDK terms; free | OK |

Nothing uses real people's voices, likenesses, music samples or third-party footage.
