# What's New - release notes

Plain words for players. Paste the newest one into each store's "What's New" /
release-notes box (Google Play 500 characters, App Store 4,000, Steam event).

## 1.0.0 (first release)
Be a bug in a house full of giants: eight bugs, three big rooms, thirty mini
maps, snap traps, crashing teacups and a hungry robot vacuum. New in this
build: Ultra graphics and a 120 fps option, bigger text (up to 200%), a
reduced-motion switch, the game pauses when you switch away, saves that
survive a crash, and optional crash reports so bugs get fixed faster.
