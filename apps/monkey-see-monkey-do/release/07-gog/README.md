# 07 · GOG

GOG is curated: you submit a pitch and they decide. There's no fee to submit; if
accepted, GOG sets up the store page and installers with you and takes a share
of sales.

## What GOG needs

- **DRM-free:** the game must run with no launcher, account or internet. The PC
  edition already does (release/05-desktop).
- **Offline installers** per platform: GOG builds these from the game files you
  upload (the `npm run build:steam` folders work as the source).
- A strong pitch, trailer and screenshots. Draft: [pitch.md](pitch.md).

## Steps

1. Launch on Steam or itch.io first if you can: GOG often asks how the game did
   elsewhere.
2. Fill in GOG's game submission form (gog.com > "Submit your game"): pitch,
   trailer, screenshots (../00-shared/screenshots/desktop-1080p), a build or key.
3. If accepted: sign the agreement, get Developer Portal access, upload builds.
   GOG Galaxy features (achievements) are optional.

GOG favours polished single-player games; the family angle, the DRM-free build
and "everything earned by playing, no purchases" are the strongest points.
