# **CANOPY CROSSING: Linux build**

**Stores:** Steam (and Steam Deck), GOG, itch.io.

`CanopyCrossing-Linux-x86_64.zip` holds one file, `CanopyCrossing.x86_64`
(the game data is inside it). 64-bit Linux with OpenGL 3.3.

**Test it:** unzip, `chmod +x CanopyCrossing.x86_64`, run it. Checked on
this machine: it starts and reaches the home screen.

**Steam Deck:** runs natively on SteamOS; for "Deck Verified" the text must
be readable at 1280x800 and every control must work on the gamepad. See
`../../LAUNCH/steam/`.
