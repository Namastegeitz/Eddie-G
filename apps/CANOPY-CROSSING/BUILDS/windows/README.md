# **CANOPY CROSSING: Windows build**

**Stores:** Steam, GOG, itch.io, Epic Games Store, Microsoft Store.

`CanopyCrossing-Windows-x86_64.zip` holds one file, `CanopyCrossing.exe`
(the game data is inside it). 64-bit Windows 10/11, OpenGL 3.3 graphics.

**Test it:** unzip on a Windows PC and run it. It opens a portrait window;
keyboard (arrows/WASD, Space, X), mouse and gamepad all work. Try resizing
the window and full screen (F11 / Alt+Enter).

**Not code-signed yet:** Windows SmartScreen will say "unknown publisher"
until the .exe is signed with a code-signing certificate (Steam and GOG
don't require one; direct downloads look more trustworthy with one).

**Before PC stores accept it:** decide the PC edition (premium, no ads or
real-money purchases is what Steam/GOG players expect), a landscape-friendly
layout for 16:9 monitors, controller support checks. See `../../LAUNCH/steam/`,
`../../LAUNCH/gog/`, `../../LAUNCH/itch-io/`.
