        Save this area offline

        Downloads every tile of the current base map inside the visible area, from this zoom level down to more detail, so the map works with no signal. Browsing the map while online also saves what you look at.

        Saved on this device

          Be kind to free tile servers

          OpenStreetMap and OpenTopoMap are run by volunteers. Their usage policies forbid heavy bulk downloading — OSM specifically forbids downloading zoom 17+ in bulk. This app caps each job, limits parallel downloads, and won't bulk-download OSM beyond zoom 16. Save only the areas you actually need. For large regions, use your own tile server (Layers → Custom).

          Go to coordinates

          Find where you are from compass bearings to 2–3 landmarks you can see and can find on the map (peaks, towers, bridges). Best results when the landmarks are 60–120° apart.

          Share my location by QR code

          Works with no network: the other phone just scans the code with its camera.

          A geo: link opens directly in map apps on most Android phones. The text format is readable by any QR scanner (including iPhone) and includes MGRS for rescuers.

          Export

          GPX opens in almost every GPS app and handheld. The JSON backup includes waypoints, tracks, checklists, rendezvous plan and settings (not map tiles).

          Compass

          Phone compasses point to magnetic north. Enter your local declination to get true bearings that match the map. Approximate values (they drift yearly — check a current chart): New Jersey ≈ −12.5 (12–13° W), Algarve ≈ −1 (about 1° W).

          To calibrate, move the phone in a slow figure-8. Keep it flat and away from metal, magnets and vehicles.
