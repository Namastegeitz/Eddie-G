ALIEN GLYPH SUDOKU — EXPORT

This folder contains the complete standalone game source and its visual assets.

FILES
- index.html: game page
- style.css: layout, colors, animations, and responsive styling
- symbols.js: all seven selectable symbol sets
- script.js: Sudoku rules, interactions, timers, sound effects, and synthesized music
- space/: six background images used by the game
- favicon.svg and opengraph.jpg: browser/social preview images
- ALL-SOURCE-CODE.txt: HTML, CSS, and JavaScript combined for copy-and-paste

TO RUN
Keep the files and space/ folder together. The easiest way to run it is to publish the folder with any static website host. You can also serve this folder locally with a simple static server and open its index.html URL. The game has no backend or package installation requirements. Google Fonts are fetched online; system fallback fonts are included.

AUDIO NOTE
Browsers block automatic audio until the player interacts with the page. The music and sound effects start after the first click or tap, and can be toggled in-game.
