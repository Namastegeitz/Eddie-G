How to install on a phone

Android (Chrome): tap Install app above, or the ⋮ menu → Install app / Add to Home screen.

iPhone / iPad (Safari): tap the Share button → Add to Home Screen. Open it once from the home screen while online so it saves itself.

GPS needs a secure address: open the app from an https:// address or http://localhost. Opening the HTML file directly (file://) blocks GPS and offline install.

Open on another phone

Scan this with the other phone's camera to open the app there, then install it on that phone too. (Needs signal on that phone the first time.)

Before you lose signal

  1. Open every page once while online (this happens automatically when the app installs) — check the “Offline-ready” chip above is green.
  2. Save your map areas: Map → Layers → Offline maps → Save this area. Do home, routes and destinations at the detail you need. Include elevation data.
  3. Get a GPS fix once and allow location permission, so it isn't a question you face in an emergency.
  4. Set magnetic declination for your area (Map → Settings) so compass bearings match the map.
  5. Mark rally points, water and caches as waypoints, and fill in the group rendezvous plan in Tools.
  6. Print the Emergency PDF and keep it with your kit — paper doesn't need a battery.
Reference only. This app supports good judgement and real training; it does not replace them. In an emergency, call for help first if you can (911 in the US, 112 in Europe and on most phones). Foraging, first aid, electricity and food-preservation content carries real risk — read the safety notes and, when in doubt, don't.

Everything stays on this device: waypoints, tracks, saved map tiles, checklists and settings are stored locally and never uploaded. Map data © OpenStreetMap contributors; terrain style © OpenTopoMap (CC-BY-SA); elevation data from public SRTM/USGS sources via Terrain Tiles.
