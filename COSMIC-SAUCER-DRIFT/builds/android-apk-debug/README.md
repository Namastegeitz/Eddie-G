# Android test APK (debug)

`cosmicsaucerdrift-debug.apk`, version 1.0.0 (build 1), signed with Godot's debug key.

- **Install on a phone:** copy it over, open it, allow "Install unknown apps" when asked.
  Or with a cable: `adb install -r cosmicsaucerdrift-debug.apk`.
- **Not for any store.** Google Play needs the signed bundle in `../android-aab-release/`.
- From 2027 Google plans to require registered developers for sideloaded apps on certified
  phones. Testers will then see an extra "advanced" install step unless the key is registered.
