# Linux build

`CosmicSaucerDrift-linux-x86_64.zip` holds `CosmicSaucerDrift.x86_64` (64-bit, game data built in).
Checked: it starts and quits cleanly on this computer.

- Run: unzip, `chmod +x CosmicSaucerDrift.x86_64`, then `./CosmicSaucerDrift.x86_64`.
- **Steam** (also covers Steam Deck), **GOG** and **itch.io** take this build.
