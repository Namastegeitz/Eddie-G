# Windows build

`CosmicSaucerDrift-windows-x86_64.zip` holds one file, `CosmicSaucerDrift.exe` (64-bit, game data built in).

- **Unsigned.** Windows SmartScreen will warn "Windows protected your PC" on direct
  downloads. Steam, GOG and Epic installs are not affected. For itch.io or a website, sign it
  with a code-signing certificate (or Microsoft's Artifact/Trusted Signing service).
- **Steam / GOG / Epic:** upload the unzipped .exe as the Windows build (depot).
- **itch.io:** upload the zip and mark it "Windows".
