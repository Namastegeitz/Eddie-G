# **COSMIC SAUCER DRIFT** · web game portals

All take the web build in [`../../builds/web/`](../../builds/web/) as a zip with index.html at the root.

| Portal | Rules | Fit |
|---|---|---|
| **Newgrounds** | No SDK needed; ~250 MB limit (unverified) | Good, same day |
| **Game Jolt** | No SDK needed; optional ad share | Good, same day |
| **CrazyGames** | *Basic Launch*: SDK optional, ≤50 MB (≤20 MB for the mobile home page), 7 days / 500 plays (max 21 days). *Full Launch*: their SDK + QA, ≤250 MB, ads only via their SDK | Our build is 46 MB: Basic Launch fits on desktop; Full Launch needs SDK work |
| **Poki** | Curated; SDK required; aims at ≤5–8 MB downloads; web-exclusive deals by default | Skip (too big, exclusivity clashes with itch.io) |

Sources: https://docs.crazygames.com/requirements/technical/ · https://docs.crazygames.com/requirements/intro/ ·
https://developers.poki.com/guide/revenue-deal-types · https://www.newgrounds.com/wiki/developer-resources/unity3d-webgl-support
