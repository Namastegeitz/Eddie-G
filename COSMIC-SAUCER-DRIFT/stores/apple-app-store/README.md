## Mac
- **Free extra reach:** the iPad build is offered on Apple-silicon Macs by default (opt out in Pricing and Availability).
- **Steam / GOG Mac build:** sign with a Developer ID certificate and **notarize** (Steam requires it for new
  Mac games). Godot 4.7 can do both from Linux with `rcodesign` and an App Store Connect API key.

## Steps (★ = needs a Mac or cloud Mac)
1. Enroll (individual, $99). Paste your Team ID in the checklist note.
2. Publish the privacy policy and support pages; answer the EU trader question.
3. Register the App ID, then create the Distribution certificate + App Store profile (or an API key for cloud builds).
4. Create the app record (name, SKU, bundle id). Claude re-exports with your Team ID.
5. ★ Archive in Xcode 26+ and upload. Then test it on TestFlight on an iPhone and an iPad.
6. Fill metadata, screenshots, age rating, "Data Not Collected", price Free, review notes → Submit.
