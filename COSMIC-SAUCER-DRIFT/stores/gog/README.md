# **COSMIC SAUCER DRIFT** · GOG

**Curated:** you apply and GOG decides. Free to apply; there's no published response time,
and rejections come without detailed feedback. Apply once the game is polished and ideally
already out elsewhere (Steam/itch), since GOG prefers finished or released games.

## Already done
- DRM-free Windows, macOS, Linux builds that need no launcher → [`../../builds/`](../../builds/)
- No accounts, no online features (GOG requires the game to run without the Galaxy client)

## Missing
- [ ] Submission form (~15 questions: developer, platforms, status, price, DLC plans)
- [ ] If accepted: contract, then key art + logo ≥1920×1080 as layered PSD from GOG's
      templates, screenshots, a trailer ending on the GOG.com logo, description, system requirements
- [ ] macOS build signed and notarized (recommended)

## Facts
| Item | Rule |
|---|---|
| Apply | https://lp.gog.com/submit-your-game/en (also via gog.com/indie) |
| DRM-free | Contractual; Galaxy SDK features optional and must fail gracefully |
| Installers | GOG builds offline installers from your Master branch automatically; avoid ~ # % * in the game name |
| Upload tools | Build Creator (GUI, has a Linux AppImage) and Pipeline Builder (CLI); portal access after signing |
| Builds due | 3–5 days before launch |
| Revenue | Historically 70/30; current terms aren't public (unverified) |
| Price parity | Keep price/content on GOG in line with other stores (GOG can hold revenue otherwise) |
