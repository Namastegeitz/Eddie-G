# **COSMIC SAUCER DRIFT** · Epic Games Store

**Cost:** $100 per product (paid back after $1,000 revenue). **Revenue:** you keep 100% of the
first $1M per year, then 88/12. **Time:** ~3–5 weeks. **Windows and macOS only** (no Linux on Epic).

## Already done
- Windows build; macOS build (needs signing + notarization: Epic has a "notarized" flag)
- No achievements and no online play, so Epic's achievement and crossplay rules don't apply

## Steps
1. Developer Portal: organization, trader verification, tax form (W-9 / W-8BEN), payout account (up to 2+ weeks; 18+).
2. Pay $100 → create the product.
3. IARC age rating in the portal (free, 5–15 min; unrated games are shown as adults-only).
4. Product page → review (2+ days).
5. Upload builds with the BuildPatch Tool (Windows/macOS documented; Linux unverified).
6. Submit for final review → release.
