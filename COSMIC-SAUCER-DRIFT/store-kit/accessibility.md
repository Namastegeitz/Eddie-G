## Apple Accessibility labels (App Store Connect > Accessibility)
Answer per device (iPhone, iPad). Only claim what the common tasks fully support:
| Label | Answer | Why |
|---|---|---|
| VoiceOver | **No** | Menus are drawn by the game, not native controls |
| Voice Control | **No** | Same |
| Larger Text | **No** | Interface size goes to 130 %, short of the system text sizes Apple expects |
| Dark Interface | **Yes** | The whole game is dark by design |
| Differentiate Without Color Alone | **No** (be safe) | Positions and items use icons and text, but some cues are colour only; the colour-blind filter helps but isn't this label |
| Sufficient Contrast | **Yes** | White and gold text on dark panels |
| Reduced Motion | **Yes** | Settings > Reduce motion |
| Captions / Audio Descriptions | **Not applicable** | No spoken dialogue or video content |
